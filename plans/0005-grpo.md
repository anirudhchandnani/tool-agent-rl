# GRPO

## Goal
Add a critic-free trainer that scores actions by comparing trajectories.

## What this adds
- algos/grpo.py: for each start and target, sample a group of trajectories and
  turn each trajectory return into a group-relative advantage by centering and
  scaling within the group. It keeps the clipped ratio and the KL penalty but
  drops the value head.

## Why it differs from PPO
PPO learns a value function to estimate the baseline. GRPO skips that and uses
the mean return of a group of samples for the same task as the baseline, so there
is no critic to train and no value loss to balance.

## Tests
- A step returns finite metrics.
- Reward goes up over a short run.
