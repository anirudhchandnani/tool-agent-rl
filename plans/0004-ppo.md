# PPO

## Goal
Add a more stable trainer that reuses each batch for several updates.

## What this adds
- algos/ppo.py: a clipped surrogate objective, a value head used as a learned
  baseline, several update epochs per batch, and a KL penalty to the reference.

## Why it differs from REINFORCE
REINFORCE throws a batch away after one update and can take large, unstable
steps. PPO clips the probability ratio so each update stays close to the policy
that collected the data, which lets it reuse the batch safely.

## Tests
- A step returns finite metrics.
- Reward goes up over a short run.
